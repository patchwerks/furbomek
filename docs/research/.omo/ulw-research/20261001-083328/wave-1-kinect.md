# Wave 1: Kinect v2 Linux driver

OpenKinect libfreenect2 is a Kinect v2 driver with RGB, IR, depth and registration: https://github.com/OpenKinect/libfreenect2/blob/fd64c5d9b214df6f6a55b4419357e51083f15d93/README.md ; native RGB 1920x1080 and depth/IR 512x424: https://github.com/OpenKinect/libfreenect2/blob/fd64c5d9b214df6f6a55b4419357e51083f15d93/include/libfreenect2/frame_listener.hpp . Registration exposes XYZRGB. USB3 mandatory, ASMedia flagged incompatible, VM passthrough risky. OBS-kinect has Linux libfreenect2 backend but self-describes support as qualified and lacks Microsoft SDK skeleton tracking: https://github.com/SirLynix/obs-kinect/blob/4d2e7b17c142183d30a843572a9a231896329260/README.md . Head is old (2020); current Ubuntu build caveat raised in issue #1202. EXPAND: modern Ubuntu fork under wave 2 and exact kit/host bench.
