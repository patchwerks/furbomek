# Wave 1: OBS/GStreamer/OpenCV pipeline

OBS Linux V4L2 source, Browser Source, window capture and obs-websocket are primary documented components: https://obsproject.com/kb/video-capture-sources ; https://obsproject.com/kb/browser-source ; https://obsproject.com/kb/window-capture-sources ; https://github.com/obsproject/obs-websocket . exeldro shaderfilter has Linux build/examples for 2D edge, pixel, scan/glitch effects: https://github.com/exeldro/obs-shaderfilter/blob/10c59eae85abb4ed306c7a2192c210aa8469f6e9/README.md#L158-L235 . Automatically tracked box, face/probe and synchronized insets still need perception state and coordinate transforms; measured 3D cloud needs depth acquisition and GL rendering. GStreamer appsrc/v4l2loopback and obs-gstreamer are proposed bridges, but inspected obs-gstreamer maps CPU buffer and should not be called zero-copy. StreamFX has current source/binary access/license ambiguity and is excluded as baseline. EXPAND: complete RGB composition prototype, capture transport benchmarks, restart/latency gate.
