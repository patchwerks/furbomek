# Wave 1: Praxis LIVE

PraxisLIVE 6.7.0 is first-party documented on Linux (DEB amd64/arm64), visual patching plus live Java, GStreamer/V4L2 video:capture, P2D/P3D, GLSL and text components. Evidence: https://www.praxislive.org/download/ ; https://docs.praxislive.org/installation/ ; https://github.com/praxis-live/praxiscore/blob/d048bdebc4140412003ee96a82b7ce2e788b0ad7/praxiscore-video-gstreamer/src/main/java/org/praxislive/video/gstreamer/configuration/GStreamerSettings.java#L46-L59 ; https://github.com/praxis-live/components/blob/9a2a66ecf73d1263345d9fb0967055f6f55225c0/VideoGL/gl-filter-base.pxg#L29-L37 . Standard capture is BGRx image data, not metric depth. Kinect bridge and dense XYZ rendering are proposed, untested. OBS window capture and OSC custom template need qualification; v6 removed old built-in OSC root. Leads: capture benchmark, external depth bridge, component licenses, restart behavior. No off-axis lead.
