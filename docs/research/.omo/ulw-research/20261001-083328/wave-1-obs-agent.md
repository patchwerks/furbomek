# Wave 1: OBS/A2UI and agent integration

OBS 28+ bundles obs-websocket; current official release observed 32.2.2: https://github.com/obsproject/obs-studio/releases/tag/32.2.2 . Pinned source shows scene switch/visibility/filter requests; protocol supports version/statistics: https://github.com/obsproject/obs-websocket/blob/1f37e6179be80af6652d5ff97d3f91b8705da81a/docs/generated/protocol.md . Separate validated stream director holds credentials; Hermes sends named effect/scene requests to broker. Browser Source can unload/refresh, so event snapshot/expiry is required: https://obsproject.com/kb/browser-source . GStreamer queues block and shmsink waits by default unless configured otherwise: https://gstreamer.freedesktop.org/documentation/coreelements/queue.html ; https://gstreamer.freedesktop.org/documentation/shm/shmsink.html . TouchEngine is a paid TD component embed and Windows/macOS SDK route, not Linux-native .tox compatibility. EXPAND: transport, alpha, dropped-frame, scene-source and renderer restart gates.
