# Movement plates

When firmware, an action mapping, or a movement test changes the actual
phase order, pose, timing, or verified result, update the matching
movement note and its numbered phase schematic in this directory in the
same change. Use the imagegen skill to generate or revise the phase
illustration from the current source and test reference. Keep the
minimal moving parts in view, then check the generation against every
affected figure and replace it if foot contact, direction, pose or
ordering disagrees.

Verify installed behavior against the firmware identity and camera
record. Keep commanded values, measured values, modeled references and
proposals labeled. Record the imagegen prompt and final asset. Reuse a
plate only when commands actually share a mechanism or alias. Keep
private camera originals and calibration material outside the repo.
