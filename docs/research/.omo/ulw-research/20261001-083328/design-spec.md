# Markdown design specification

Destination: repository research note. Markdown, no generated raster assets required. Existing `docs/research` evidence-note structure is the template.

Structure: decision summary; exact footage inventory; camera facts; ranked stack matrix and detailed assessments; reference architecture; effect implementation and acceptance tests; open questions; numbered primary sources with access dates; methodology.

Lineage: inline

Figures: Mermaid only where it clarifies pipeline ownership, with labels and source note. No embedded footage because original attachment is private and outside Git. Tables remain readable in Markdown. Every market price is dated and caveated. Evidence labels follow this repo's README and AGENTS.md.
