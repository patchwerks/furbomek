# Wave 1: recognition and cloud

Marker recognition (AprilTag/ArUco) identifies tagged props; homography handles planar targets; correlation trackers follow an initialized box but do not recognize identity; MediaPipe face/pose supplies person landmarks; detector plus ByteTrack can follow predefined categories with a separate model/license choice. Primary sources: https://docs.opencv.org/4.13.0/d5/dae/tutorial_aruco_detection.html ; https://github.com/AprilRobotics/apriltag/blob/b7c0ebe9aa20f82ec7a828579004f9e706bfecd9/apriltag.h#L201-L230 ; https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python ; https://github.com/OpenKinect/libfreenect2/blob/fd64c5d9b214df6f6a55b4419357e51083f15d93/src/registration.cpp#L342-L359 . Measured Kinect depth can project metric XYZ; Depth Anything V2 base outputs relative estimates, with model-dependent licenses. Proposed event contract carries timestamp, normalized box, state, score type and TTL; separate binary path for depth/masks/point payloads. Leads: select object categories/marker policy and benchmark actual inference/tracking; no performance claim.
