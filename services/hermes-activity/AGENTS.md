# Public activity projection

Read root guidance and the module README. This is a reduced presentation adapter,
not a second planner, raw tool surface, complete A2UI engine or speech stack.

- Preserve real observer-to-spool-to-broker-to-Godot interface tests, not only reducers.
- Preserve cursor/checkpoint consistency, original event time, monotonic publication
  sequence, TTL, redaction and failure truthfulness. Never invent tasks to fill the HUD.
- Hooks return no directives and start no desktop/services. Never expand their authority.
- Live desktop screenshot policy is unqualified and rejected before activation.
  Default off is supported; do not bypass it through helper functions or timeouts.
- Preserve safe-key/URL projection; no raw arguments, results, paths, secrets or pixels
  in public events. Test failure markers without claiming they certify screen privacy.
- Run the locked pytest, Ruff/format, basedpyright and lock gates. Root
  `tools/verify-media.sh` includes consumer fixtures. Live qualification belongs in
  the operations record; no robot/serial/head access is needed for these tests.
